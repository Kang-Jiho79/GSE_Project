### 2.1 아트 디렉션
단순한 모델도 **색, 실루엣, 조명, 이펙트**로 분위기를 끌어올리는 것을 기본 방향으로 한다.

| 대상 | 색 |
|---|---|
| 빛 | 금색, 흰색 |
| 어둠 | 보라, 먹색 |
| 잿빛 | 회색, 은색 |
| 신 (「   」) | [색 없음 / 투명 / 빛과 어둠이 섞인 색] [ ] |

**실루엣 규칙**
- 쿼터뷰는 멀리서 보이므로 디테일보다 **실루엣과 색**으로 소속(빛/어둠)을 구분
- 빛 소속은 곧고 각진 형태, 어둠 소속은 낮고 날카로운 형태 [제안]

**모델 제작 방식**
- 현재 모델은 코드로 생성한 단순 모델
- 방향: **코드로 생성하는 모델을 유지**하고, 부위 조합·비율·실루엣을 개선한 뒤 렌더링 연출(블룸, 아웃라인, 파티클)로 보완 (직접 모델링은 하지 않음)
- 모델 개선 원칙 (제안)
  - 몸통·머리·팔다리를 분리된 부위로 만들고 비율을 의도적으로 과장 (큰 머리, 긴 팔다리 등)
  - 소속을 알리는 **실루엣 소품**을 추가 (빛: 날개 모양·후광, 어둠: 뿔·망토 등)
  - 보스는 일반 몬스터보다 크게, 부위 수를 늘려 존재감 부여
  - 걷기·공격 시 부위별 움직임(흔들림, 기울기)으로 단순한 모델도 살아 있게 표현
- 무료 외부 에셋(저작권 자유 모델)은 모델 불러오기 기능이 필요하므로 지금은 도입하지 않음 [나중에 필요하면 재검토]

**렌더링 연출 (OpenGL)**
- 블룸(발광 번짐): 스킬과 빛나는 부위 강조
- 림라이트와 아웃라인(셀 셰이딩): 단순한 모델에 스타일 부여
- 안개와 색보정: 잿빛 지대는 탁한 회색빛, 수도는 선명하게 → 세계관 표현
- 파티클과 잔상: 스킬, 폼 전환, 피격에 사용

**스킬과 타격감**
- 히트 스톱(타격 순간 잠깐 멈춤), 화면 흔들림, 타격 이펙트, 효과음
- 폼 전환의 **교대 스킬**을 가장 공들여 연출 (빛과 어둠이 서로 터지는 표현)

**UI**
- 빛의 힘, 어둠의 힘을 **화면 왼쪽 위의 다이아몬드 게이지**(반씩 채우는 방식, 현재 구현)로 보여주고, 여기에 **균형도 표시를 추가** (신전의 균형 점검과 연결)
  - 다이아몬드 게이지는 **다음 강화까지의 그릇**을 보여줌 (강화 시 비워짐). 균형도는 그릇이 아니라 **누적 흡수량**으로 계산 (5.4, 6장)
- 균형이 무너지면 UI가 잿빛으로 물드는 연출 [제안]
- 지역(솔라, 녹스, 잿빛 지대)에 따라 UI 색감이 달라지는 연출 [ ]

## 3. 세계관

### 3.1 시대
- **빛과 어둠의 전쟁의 시대** → **잿빛의 시대**
- 빛의 나라와 어둠의 나라가 전쟁을 벌이던 중, 최초의 잿빛의 존재가 등장하며 세계가 잿빛으로 뒤덮임
- 각 나라는 점점 힘을 잃으며 잿빛에 잠식되고 있음

### 3.2 지역
| 지역 | 설명 |
|---|---|
| 루멘 | 빛의 나라의 수도. 잿빛에 물들지 않은 몇 안 되는 곳 |
| 테네브라에 | 어둠의 나라의 수도. 잿빛에 물들지 않은 몇 안 되는 곳 |
| 잿빛 지대 | 두 수도를 제외한 나머지 세계 전체 |
| 경계인의 숨은 마을 (리미나) | 주인공이 자란 마을. 힘 약한 경계에서 태어난 자들이 숨어 삶 |
| 크레푸스 | 두 나라의 경계 지역. 빛·어둠 기운이 고르게 섞여 있음 |
| 벨룸 평원 | 두 나라 사이의 전쟁터이자 허브. 잿빛 농도가 짙음 |
| 솔라 | 빛의 땅. 수도 루멘으로 이어짐 |
| 녹스 | 어둠의 땅. 수도 테네브라에로 이어짐 |
| 디비시오 | 빛과 어둠의 전선. 중심지 근처 마을들 사이 |
| 키네라 | 잿빛의 중심지. 키니스와 관련된 곳 |
| 공백 | 신의 영역. 이름이 비어 있는 신에 어울리는 이름 |

#### 지역 동선
```
리미나(경계인의 숨은 마을) → 크레푸스(나라의 경계 지역) → 벨룸 평원(전쟁터, 허브)

벨룸 평원 → 솔라(빛의 땅): 마을 2곳 → 신의 말 관문 → 수도 루멘 → (텔레포트) → 벨룸 평원
벨룸 평원 → 녹스(어둠의 땅): 마을 2곳 → 신의 말 관문 → 수도 테네브라에 → (텔레포트) → 벨룸 평원

벨룸 평원 → 잿빛의 중심지 근처: 각 나라의 마을 2곳씩(총 4곳) → 디비시오(전선) → 키네라 → 신의 영역(공백)
```
- **벨룸 평원은 허브**: 두 나라 사이의 전쟁터이자 각 지역으로 가는 갈림길
- 솔라와 녹스는 **순서를 플레이어가 선택** (한 나라의 수도를 마치면 벨룸 평원으로 돌아옴)
- 수도에 도달하면(왕 결투·추궁 등을 마치면) **벨룸 평원으로 텔레포트**됨 → 텔레포트의 이유 연출: [신의 힘이라는 복선 / 왕의 힘 / 수도의 문] [제안: 신의 힘]
- 수도 방문은 필수가 아니며, **벨룸 평원에서 바로 잿빛의 중심지 근처로 갈 수 있음** (왕의 인정은 선택, 4.4 참고)
- **유도 방식**: 강제하지 않고, 가는 길에 만나는 사람들의 대화로 "왕의 인정을 받으면 좋을 것"이라고 권함
  - 솔라·녹스의 마을 NPC: "왕의 인정을 받으면 **버프(축복)** 를 받는다"는 소문을 전함
  - 벨룸 평원의 갈림길 안내(NPC 또는 표지): 각 나라의 수도 방향을 알려줌
  - 이미 왕의 인정을 받은 경우에는 해당 권유 대사가 나오지 않음
  - 권유는 "버프를 받는다"는 이점 수준으로만 하고, 인정 여부가 엔딩을 바꾼다는 점은 알리지 않음 → 플레이어는 "강해지기 위해" 수도로 가게 됨
- 벨룸 평원에는 빛·어둠 소속 몬스터가 섞여 나옴 → 한쪽 땅에서 쏠린 힘을 맞추는 **균형 회복 구간**으로 활용 가능 [제안]

#### 맵 구성과 이동 (구현)
- **맵 21개**: 마을·들판·관문·수도가 각각 하나의 맵
  - 경계: 리미나(마을) — 리미나 숲 — 크레푸스 — 벨룸 평원
  - 빛의 땅: 벨룸 — 알바 — 솔라(들판) — 아우라 — 빛의 관문 — 루멘
  - 어둠의 땅: 벨룸 — 움브라 — 녹스(들판) — 크립타 — 어둠의 관문 — 테네브라에
  - 잿빛: 벨룸 — 잿빛 변경(들판) — 피데스·스페스·레퀴엠·루크투스(각각 연결) / 잿빛 변경 — 디비시오 — 키네라
  - 리미나 숲, 솔라, 녹스, 잿빛 변경, 빛의 관문, 어둠의 관문은 임시 이름 [확정 필요]. 신의 영역(공백)은 진엔딩 전용으로 나중에 추가
- **이동**: 맵마다 도착 지점에 이동 지점(돌기둥)이 있고, 거기서 F → **월드맵**. 연결된 이웃 지역과 **한 번 가본 지역**은 어디든 선택해 이동 (빠른 이동). 수도에서 벨룸으로 돌아오는 것도 이 빠른 이동으로 처리
- **몬스터**: 지역에 들어올 때마다 새로 채워짐. 지역마다 몬스터 수와 빛·어둠 비율이 다름 (솔라는 빛 위주, 녹스는 어둠 위주, 벨룸·변경은 섞임)
- **분위기**: 지역 양식에 따라 안개 색·밝은 범위·채도·대비·색조가 다름. 잿빛 지대는 탁한 회색, 키네라는 색이 거의 없음, 솔라는 금빛, 녹스는 보랏빛, 두 수도는 가장 선명
- 마을 안에는 몬스터가 나오지 않음 (잿빛 마을 4곳은 예외). 집과 신전은 통과할 수 없음

| 위치 | 솔라 (빛의 땅) | 녹스 (어둠의 땅) |
|---|---|---|
| 수도 가는 길 마을 1 (변경, 전쟁터의 흔적) | 알바 (새벽) | 움브라 (그림자) |
| 수도 가는 길 마을 2 (큰 신전) | 아우라 (빛의 숨결) | 크립타 (지하 묘실) |
| 관문 | 신의 말 (빛) | 신의 말 (어둠) |
| 수도 | 루멘 (루키우스) | 테네브라에 (녹티스) |
| 잿빛의 중심지 근처 마을 1 | 피데스 (신앙) | 레퀴엠 (안식) |
| 잿빛의 중심지 근처 마을 2 | 스페스 (희망) | 루크투스 (애도) |

- 마을 이름은 초안 (라틴어 계열) [확정 필요]
- **잿빛의 중심지 근처 마을 4곳**: 잿빛에 잠식된 마을들. **정화로 사람들을 구하고(5·8단계), 엿듣기 이벤트와 이명 "신에게 선택받은 자" 획득이 일어나는 곳** (4.3)
- 마을 분위기: 솔라는 흰 석조와 금색의 높은 건물, 녹스는 어두운 석재와 보라·먹색의 낮고 깊은 건물 [제안]
- 솔라와 녹스의 신전은 외관은 다르지만 **내부 평면도는 같게** 만들어 같은 신을 모신다는 복선으로 사용 [제안]

#### 마을과 신전
- 맵 곳곳에 **마을**이 있고, 각 마을에는 여러 건물과 함께 **반드시 신전**이 있음
- 신전은 "두 나라 모두 하나의 신을 믿는다"는 설정(4.3의 8단계)과 이어지는 장소 → 세계의 이상한 점의 단서가 되는 곳 [제안]
- 빛의 마을과 어둠의 마을은 같은 신을 모시지만 신전의 양식이 다름 [제안]
- **신전의 기능**
  - **저장과 체력 회복**: 제단에서 저장하고 휴식 (저장은 9단계). 체력이 모두 회복되고, 이후 쓰러지면 **이 제단 앞에서 부활** (다른 지역에서 쓰러져도). 몬스터는 신전과 별개로 지역에 들어올 때마다 다시 채워짐
  - **균형 점검**: 제단에서 현재 빛의 힘·어둠의 힘과 균형도를 확인 ("신이 힘의 균형을 비춰준다"는 설명으로 흡수 시스템의 정보 창구 역할)
  - **복선 장치**: 8단계에서 신의 영향을 벗어난 뒤에는 사제 NPC에게 신에 대해 물으면 왕처럼 **오류 반응**(같은 말 반복, 화냄)을 보임 → 수없이 이용한 장소가 다르게 느껴지게 함
- **마을 건물 구성**
  | 건물 | 용도 |
  |---|---|
  | 신전 | 필수 (위 기능) |
  | 주거지 | 분위기, NPC 대화, 퀘스트 |
  | 광장·게시판 | 의뢰, 소문 (왕의 인정 버프 소문, 엿듣기 이벤트의 무대) |
- 마을 종류별 분위기: 빛의 마을, 어둠의 마을, 경계인의 마을, 잿빛에 잠식된 마을로 건축 양식과 색감을 달리함
- 경계인의 숨은 마을에 신전이 있는가: **없음** (박해받아 온 경계인은 어느 쪽 신앙과도 거리를 둠). 신전을 처음 쓰기 전에는 리미나의 돌기둥에서 부활하고, 첫 신전은 알바·움브라에서 만남
- 잿빛에 잠식된 마을의 신전: **폐허지만 제단은 살아 있음** → 잿빛 한가운데서도 신의 힘은 끊기지 않는다는 위화감
- 신전 건물은 나라마다 다르지만(빛: 높은 석조와 첨탑, 어둠: 낮고 무거운 검은 석재와 가시, 잿빛: 무너진 폐허) **제단은 어디서나 똑같은 모양**이며 같은 흰 표식이 떠 있음 (같은 신을 모신다는 복선)

### 3.3 종족 (존재의 4가지 구분)
| 구분 | 설명 |
|---|---|
| 빛의 피조물 | 빛의 나라의 사람들 |
| 어둠의 피조물 | 어둠의 나라의 사람들 |
| 경계에서 태어난 자 | 빛과 어둠의 경계에서 태어난 자. 잿빛 이전부터 존재했으며 어느 나라에서도 받아들여지지 않고 노예·괴물 취급을 받음. 잿빛 이후에는 잿빛의 존재가 될 수 있다는 이유로 **즉시 사살 대상**이 됨 |
| 잿빛의 존재 | 빛과 어둠의 힘을 모두 소모한 경계에서 태어난 자가 변한 존재 |

### 3.4 두 나라의 왕
| 구분 | 빛의 왕 | 어둠의 왕 |
|---|---|---|
| 이름 | 루키우스 | 녹티스 |
| 수도 | 루멘 | 테네브라에 |
| 성격 | 기본적으로 선하지만 어딘가 **뒤틀려 있음** | 기본적으로 악하고 폭력적이지만 **이성적인 지략가** |
| 주인공에 대한 태도 | 달갑지 않아 함 (잿빛의 존재가 될 수 있는 자) | 달갑지 않아 함 (잿빛의 존재가 될 수 있는 자) |
| 다루는 힘 | 빛 | 어둠 |
| 주인공과의 관계 | 주인공은 왕이 다루는 힘의 대적점인 어둠도 함께 다룸 | 주인공은 왕이 다루는 힘의 대적점인 빛도 함께 다룸 |

**공통점**
- 두 왕 모두 주인공을 경계하며, 경계에서 태어난 자를 사살하는 법의 뿌리에 있는 인물
- 주인공이 자신의 힘을 넘어설 때 비로소 인정 (결투에서 승리)
- 인정 이후에도 서로에 대한 적대는 유지 → 스토리 9단계(빛과 어둠의 재충돌)로 이어짐
- **두 왕은 과거에 결탁한 공범**: 적대하던 두 왕이 공동의 위협을 없애기 위해 손을 잡았음. 그러나 이 결탁은 사실 **신의 계략**이었음 (3.5 참고) → 이후 재충돌(9단계)이 "원래 관계로의 복귀"이자 "결탁의 결과에 대한 책임 회피"로 읽히게 됨
- 두 왕은 **신과 직접 연결된 존재** → 힘이 강해도 신의 영향 아래에 있음 (3.6 참고)
- 두 왕이 자신들의 결탁이 신의 계략이었다는 것을 알고 있었는가: [몰랐음 (신의 말로 움직임) / 일부 알고 있었음]
- 진실이 드러나는 시점: [최초의 잿빛의 존재와의 대면 시 / 각 왕과의 결투 중 / 진엔딩 루트에서만]

**빛의 왕 (초안 제안)**
- 선의로 움직이지만 그 선의가 뒤틀려 있음 → 예: "모두를 지키기 위해서" 경계인의 희생을 당연시하고, 스스로는 옳다고 믿음
- 겉으로는 온화하고 자비로운 태도, 그러나 주인공을 대할 때 미묘한 위화감
- 어둠의 왕과 결탁해 최초의 잿빛의 존재를 없애는 계략에 가담 — 이를 "모두를 지키기 위한 일"이라고 스스로 정당화 (뒤틀린 선의를 보여주는 핵심 요소)

**어둠의 왕 (초안 제안)**
- 폭력을 거리낌 없이 쓰지만 감정에 휘둘리지 않고, 계산된 판단을 함
- 전쟁도 협상도 이득이 되면 선택하는 실리주의
- 빛의 왕과 결탁한 계략의 설계자 역할이 어울림 (지략가) — 주도자 여부: [어둠의 왕이 주도 / 대등하게 공모]
- 결탁조차 실리적 판단의 결과 — 목적을 이룬 뒤에는 다시 적으로 돌아설 준비를 하고 있었음 [확정 필요]


### 3.5 세계의 진실 — 신의 놀이판
> 이 진실은 게임 후반에 걸쳐 **단계적으로** 드러난다. (공개 단계는 4.3 참고)

- 이 세계는 **신이라는 존재의 놀이판**이며, 그 놀이는 **빛과 어둠의 전쟁**이다.
- 빛과 어둠의 존재들은 **본인의 의지와 상관없이 서로를 죽이려는 본능**이 새겨져 있다.
- 놀이판을 망치려는 **훼방꾼**(경계를 전쟁으로부터 지키려던, 최초의 잿빛의 존재가 되기 전의 그)이 나타나자, 신은 그를 없애기 위해 **두 왕을 결탁시키는 계략**을 꾸몄다.
- 그러나 계략의 결과로 **잿빛의 존재가 탄생**했고, 이는 **신의 예상 밖**이었다. 잿빛으로 전쟁이 멈추고 놀이가 엉망이 될 위기에 처했다.
- 이에 신이 **직접 개입**해서 내보낸 존재가 **플레이어(주인공)**이다.
- 그래서 주인공은 **쓰러뜨린 이의 힘을 흡수하는 능력**과 **높은 잠재력**을 가졌다.
- 신의 목적: 잿빛을 없애 **놀이를 원래대로 되돌리는 것**
- 고유 이름: 최초의 잿빛의 존재 = **키니스**, 신 = **「   」** (이름이 비어 있는 존재로 표기)
- **신의 말**: 신이 놀이판에 직접 둔 수호자 형태의 존재 (3장 보스). 놀이가 유지되도록 지키는 장치 [제안, 확정 필요]

**전체 인과 흐름**
```
신의 놀이(빛과 어둠의 전쟁) → 훼방꾼 등장 → 신이 두 왕의 결탁을 유도해 제거 시도
→ 예상 밖의 결과: 최초의 잿빛의 존재 탄생, 놀이가 멈춤 → 신이 주인공을 개입시킴
→ 주인공이 잿빛을 거두며 놀이를 되돌림 (신의 의도) → 진실을 알게 된 주인공의 선택
```

**이 설정이 기존 요소와 이어지는 지점 (초안 제안)**
| 기존 요소 | 신의 놀이판 설정과의 연결 |
|---|---|
| 경계에서 태어난 자 | 빛과 어둠의 힘이 균형을 이루어 **본능이 상쇄된 존재** → 놀이판의 규칙 밖에 있어서 두 나라가 두려워하고 박해해 온 것 [확정 필요] |
| 잿빛의 존재 | 본능에서 벗어나 **놀이를 멈춘 존재**. 신에게는 "예상 밖의 고장" |
| 두 왕의 결탁 | 서로를 죽이려는 본능을 거슬러 손을 잡은 행위 — 하지만 **신의 계략**이라 스스로 본능을 넘은 것은 아님 |
| 주인공의 흡수 능력 | 신이 놀이를 되돌리기 위해 준 능력 (잿빛을 거두는 힘의 기원) |
| 주인공 이름을 플레이어가 정함 | 신이 보낸 "플레이어"라는 메타적 의미와 일치 |

**미해결 설정**

- 진실의 공개 단계: 4.3 스토리 흐름 참고 (결탁 → 위화감 → 하나의 신 → 전체 진실)

### 3.6 신의 영향력
신의 놀이판 안의 존재들은 **신의 영향력** 아래에 있고, 영향력은 존재의 **힘이 강할수록 닿지 않는다**.

| 상태 | 대상 | 겉으로 드러나는 모습 |
|---|---|---|
| 영향 아래 | 대부분의 빛·어둠의 존재 (서로를 죽이려는 본능이 작동) | 신과 관련된 질문에 **오류가 걸린 듯** 알아듣지 못하고, 이전에 했던 말을 반복하며 화를 냄 |
| 영향 이탈 | 힘이 일정 이상 강해진 존재 (주인공) | 세계의 이상한 점을 알아차리고 의문을 품게 됨 |
| 영향 재진입 | 힘이 약해진 존재 (예: 최초의 잿빛의 존재) | **신의 영향에서 벗어난 상대**(진엔딩 조건 충족자)와는 대화가 통하지 않고 곧바로 전투. 영향 아래에 있는 상대(조건 미충족자)와는 대화 가능 [제안, 확정 필요] |

- 주인공은 이명 **"신에게 선택받은 자"** 를 얻는 시점부터 신의 영향에서 벗어남 (힘이 일정 이상 강해진 시점)
- 주인공이 잿빛의 존재를 처치하며 나아가는 동안 잿빛이 줄어 최초의 잿빛의 존재의 힘이 약해지고, 그 결과 신의 영향권에 다시 들어감 → 주인공의 성장이 의도치 않게 대화의 기회를 없앤 구조
- 영향 아래 NPC의 "오류 반복" 연출은 위화감을 주는 핵심 장치
  - 오류 연출 방식: [같은 대사 반복 / 화면 지직거림 / 표정 변화 / 효과음]
  - 영향 이탈 기준: [힘 수치 임계 / 스토리 이벤트로 고정]
- 왕들은 **신과 직접 연결된 존재**이므로 힘이 강해도 영향 아래에 있으며, 그래서 결탁을 추궁받으면 오류 반응을 보임

## 4. 스토리

### 4.1 게임 시작 전 이야기
1. 경계에서 태어난 자들은 오래전부터 두 나라 모두에게 박해받아 왔다.
2. 그중 가장 뛰어난 자는 **"가장 어두운 빛, 가장 밝은 어둠"** 이라는 이명을 가졌으며, 전쟁으로부터 경계가 피해를 입지 않도록 힘쓰고 있었다.
3. 그러나 빛과 어둠의 계략으로 소중한 사람을 잃고, 빛과 어둠의 힘을 모두 소모하여 **최초의 잿빛의 존재**가 되었다.
   - **계략의 진실**: 빛의 왕과 어둠의 왕이 **결탁**한 일. 그는 너무 강해져 빛과 어둠의 전쟁이 빛·어둠·경계의 **3개 세력 구도**로 바뀔 위험이 있었고, 두 왕은 그렇게 되기 전에 그를 없애려 했다.
   - **그 뒤의 진짜 원인**: 이 결탁은 놀이판을 망치려는 그를 없애려던 **신의 계략**이었다 (3.5). 잿빛의 존재가 탄생한 것은 신의 예상 밖이었다.
   - 결과적으로 계략이 그를 잿빛의 존재로 만들었고, 두 왕의 손으로 세계가 잿빛에 잠식되는 원인이 됨
4. 빛과 어둠은 그에게 속수무책으로 당하며 잿빛으로 물들어 갔고, 잿빛의 힘은 강해지고 빛과 어둠의 힘은 약해져만 갔다.
5. 두 나라는 잿빛을 두려워해 경계에서 태어난 자를 즉시 사살하는 법을 만들었다.

### 4.2 주인공
- **이름**: 플레이어가 직접 입력
- **종족**: 경계에서 태어난 자로 알고 자람 (실제는 신이 보낸 존재 — 아래 참고)
- **잠재력**: 최초의 잿빛의 존재와 동등한 수준
- **배경**
  - 경계에서 태어난 자들이 숨어 사는 마을 **근처 숲에 버려진 아이**
  - 마을 사람들이 거두어 키웠고, 주인공은 그들을 **가족**으로 알고 자람
  - 부모에 대한 단서가 전혀 없고, 출생에 대해 마을 사람들도 아는 것이 없음
- **출생의 비밀 (반전 요소, 후반에 드러남)**: 주인공은 놀이판을 되돌리기 위해 신이 개입해 내보낸 존재 (3.5 참고). 숲에 버려진 것은 신이 주인공을 세계에 놓은 방식
- **동기**
  - 숨은 마을은 힘 약한 경계인만 있어 잿빛의 표적이 되지 않았음
  - 하지만 주인공이 자랄수록 강한 잠재력 때문에 숨어 지내기 어려워짐
  - 결국 잿빛의 존재들이 마을을 습격하고, 주인공이 맞서 싸우게 됨

### 4.3 스토리 흐름
```
습격과 상실 → 여정 → 빛·어둠과의 충돌 → 최초의 잿빛의 존재와 첫 대면 (결탁의 진실)
→ 성장 · 정화의 힘 → 두 왕의 인정 → 왕에게 추궁 (오류 반응, 위화감)
→ 피조물 구원 · 엿듣기 (하나의 신) → 신에게 선택받은 자, 신의 영향 이탈
→ 세계에 대한 의문 · 빛과 어둠의 재충돌 → 최초의 잿빛의 존재와 전투
→ 죽기 직전의 대화 (세계의 진실) → 엔딩 분기
```
> 단계 순서는 전달받은 사건 순서를 기반으로 한 초안. 4번의 정확한 시점은 [ ]
> **6~8단계는 필수가 아니며**, 하지 않으면 엔딩이 달라진다. 10단계 이후도 진엔딩 조건 충족 여부에 따라 달라진다 (4.4 참고)

| 단계 | 사건 | 드러나는 진실 | 주인공의 감정 |
|---|---|---|---|
| 1. 습격 (프롤로그) | 잿빛의 존재들이 숨은 마을을 습격, 가족처럼 지내던 사람들을 잃음 | — | 상실, 분노 |
| 2. 여정의 시작 | 잿빛의 존재들을 없애는 것을 목표로 여정을 떠남 | — | 복수심 |
| 3. 빛·어둠과의 충돌 | 빛과 어둠의 피조물들을 만나 싸움 (경계인 즉시 사살법) | — | 적대 |
| 4. 최초의 잿빛의 존재와 첫 대면 | **대화가 가능**. 그를 통해 **빛의 왕과 어둠의 왕이 결탁**했음을 알게 됨 | 결탁 | 충격 |
| 5. 성장 | 힘이 강해지며 **잿빛의 기운을 거둘 수 있는 힘**을 얻음 | — | 희망 |
| 6. 두 왕의 인정 | 각 왕과의 결투에서 승리해 인정받고 이명 **"가장 어두운 빛이자 가장 밝은 어둠"** 획득 | — | 성취 |
| 7. 왕에게 추궁 | 결탁에 대해 왕에게 **물어볼지를 대화 선택지로 선택**. 물어보면 왕이 **오류가 걸린 듯** 알아듣지 못하고 이전에 했던 말을 반복하며 화를 냄. 묻지 않으면 위화감을 느끼지 못함 | 위화감 | 의문 |
| 8. 구원과 엿듣기 | 빛과 어둠의 피조물을 구하다 그들의 대화를 엿들음 → **두 나라 모두 하나의 신을 믿고 있음**. 이명 **"신에게 선택받은 자"** 획득, 힘이 일정 이상 강해져 **신의 영향에서 벗어남** | 신의 존재 | 혼란 |

| 12. 선택 | 엔딩 분기 (4.4) | — | — |

### 4.4 엔딩 분기
최초의 잿빛의 존재를 쓰러뜨리고 죽기 직전 세계의 진실을 전해 들은 뒤, **이전에 쌓은 조건**과 **마지막 선택**으로 엔딩이 갈린다. (4.3의 11~12단계)

#### 분기 조건
| 조건 | 내용 | 관련 단계 |
|---|---|---|
| **A. 왕들의 인정** | 빛의 왕·어둠의 왕과의 결투에서 승리해 인정받음 (이명 "가장 어두운 빛이자 가장 밝은 어둠") | 6 |
| **B. 신에게 선택받은 자** | 왕에게 결탁에 대해 **물어보고**(대화 선택지) 위화감을 느낀 뒤, 하나의 신에 대한 단서를 얻어 이명 "신에게 선택받은 자" 획득 | 7~8 |
| **진엔딩 조건** | A와 B를 **모두** 충족 | — |
| **보스의 제안** | 진엔딩 조건 **미충족** 시, 최초의 잿빛의 존재와 **전투 전에 대화 가능**. 함께 잿빛이 되어 빛과 어둠을 없애자는 제안 | 10 |

#### 엔딩 경로
| # | 상태 | 선택 | 결과 |
|---|---|---|---|
| 1 | 왕들의 인정 없음 | 보스의 제안 거절 → 보스 처치 | 잿빛을 없애고 빛과 어둠의 전쟁이 재개됨 |
| 2 | 왕들의 인정 있음, "신에게 선택받은 자" 없음 | 보스의 제안 거절 → 보스 처치 | 위화감을 느끼지 못해 1번과 동일한 엔딩 |
| 3 | 진엔딩 조건 없음 | 전투 전 대화에서 보스의 제안 **수락** (보스전 없음) | 보스와 같은 **잿빛의 존재가 되어 빛과 어둠을 없앰** |
| 4 | 진엔딩 조건 있음 | 보스 처치 후 잿빛을 받아들이지 않음 | 전쟁이 재개되고, 신의 영향을 벗어난 주인공은 위험하다 판단되어 **신의 계략에 의해 죽임을 당함** |
| 5 | 진엔딩 조건 있음 | 보스 처치 후 잿빛을 받아들임 | 빛·어둠·잿빛 세 힘으로 신과 전투 → **진엔딩** |

| 진엔딩 조건 | 선택 지점 | 선택 | 엔딩 |
|---|---|---|---|
| 미충족 | 보스전 전 대화 | 거절 → 보스 처치 | **구원자 엔딩** (1·2번) |
| 미충족 | 보스전 전 대화 | 수락 (보스전 없음) | **잿빛 엔딩** (3번) |
| 충족 | 보스 처치 후 | 잿빛 거부 | **신의 계략 엔딩** (4번, 이름 [ ]) |
| 충족 | 보스 처치 후 | 잿빛 수락 | **진엔딩** (5번) |

#### 엔딩 상세
| 엔딩 | 주인공의 위치 | 놀이판 관점의 의미 |
|---|---|---|
| 구원자 엔딩 | 세계의 구원자이자, 영원한 전쟁을 다시 연 자 | 신이 원하던 대로 **놀이를 되돌림**. 신의 의도대로 임무를 완수한 결말 |
| 잿빛 엔딩 | 빛과 어둠을 버리고 잿빛이 된 자 (최초의 잿빛의 존재와 같은 길) | 놀이판의 두 축인 빛과 어둠 자체를 없애 놀이를 끝냄. 평화가 아닌 **소멸**로 끝남 |
| 신의 계략 엔딩 | 신에게 제거당한 자 | 신의 영향을 벗어난 존재는 놀이판에 위험 → 제거하고 **놀이가 계속됨** |
| 진엔딩 | 신의 놀이판을 끝낸 자 | **신을 쓰러뜨리고 본능을 지움** → 빛과 어둠이 스스로의 의지로 사는 세계 |

- 일반 엔딩은 모두 "완전한 해피엔딩"이 아닌 대가가 있는 결말. 진엔딩만이 본능 자체를 없앰
- **잿빛 엔딩의 변이**는 게임 중 한쪽 힘이 너무 강해져 균형이 무너져 잿빛에 물드는 것(5.4, 사망)과 다름. 최초의 잿빛의 존재처럼 **스스로 빛과 어둠을 버리고** 잿빛이 되는 선택
- 신의 계략 엔딩은 진엔딩 조건을 갖춘 플레이어에게만 열리는 함정 엔딩 → 선택의 무게를 알 수 있도록 [경고 연출 / 선택지 문구 / 대사 암시] [ ]
- **조건 미충족자의 11단계(죽기 직전 대화)**: 신의 영향 아래에 있어 대사가 오류처럼 끊기며 **뜨문뜨문** 들림. 단, 플레이어는 핵심 진실(신의 놀이판, 서로를 죽이려는 본능, 결탁이 신의 계략이었다는 것)을 **충분히 이해할 수 있어야 함**
  - 연출 원칙 (제안)
    - 끊기는 중에도 핵심 단어(신, 놀이, 본능, 결탁 등)는 반드시 들리게 함
    - 앞뒤 문맥으로 빈칸을 추론할 수 있도록 문장 구성
    - 들은 대사 조각을 기록(로그)에 저장해 다시 읽을 수 있게 함
    - 대화 직후 주인공의 독백으로 의미를 정리해 줌 (놓친 부분을 되새기는 형태)
    - 7단계 왕의 오류 연출과 같은 연출 문법(같은 효과음·화면 효과)을 써서 "신의 영향"임을 인지하게 함
  - 조건 충족자는 끊김 없이 전체 진실을 들음 [제안, 확정 필요]

### 5.2 조작
| 입력 | 행동 |
|---|---|

### 5.3 전투 시스템

#### 폼 시스템
**밸런스 원칙**: 빛은 안전하지만 화력이 낮고, 어둠은 위험하지만 화력과 회복이 높다. 어둠의 피흡이 근접의 위험 부담을 상쇄한다.

| 구분 | 빛폼 (원거리) | 어둠폼 (근거리) |
|---|---|---|
| 기본 공격 (좌클릭) | 광탄 연사. 피해는 낮지만 안전하게 계속 사격 | 3연타 베기. 마지막 타격이 가장 강하고 피흡 효율도 높음 |
| 스킬 (E) | **관통 광선** — 일직선으로 관통, 줄지어 선 적에게 효율적 | **돌진 베기** — 짧게 파고들어 베는 접근기 겸 공격기 |
| 특수 스킬 (Q) | **광역 낙뢰** — 지정 위치에 낙뢰. 발동이 느리고 쿨타임이 길지만 범위가 넓음 | **회전 베기** — 잠시 동안 범위 공격, 이 동안 피흡 비율 2배 |

| 약점 | 적이 접근하면 불리 | 접근해야 하는 위험 |
| 이동 속도 | [ ] | [ ] |

- 폼 전환 조작: **Space**
- 폼 전환 제한: **전환 쿨타임 있음** (쿨타임 중에는 Space 입력 불가)
- 스킬 위력은 해당 힘의 누적 수치에 비례 → 빛만 키우면 어둠 스킬이 약해지므로 양쪽 균형을 맞추게 되어 흡수 시스템과 연결됨

#### 어둠폼 피흡
- 가한 피해의 일정 비율만큼 HP 회복: **9%** (회전 베기 중 18%). 실제로 들어간 피해 기준 (남은 체력을 넘는 피해는 계산하지 않음)
- **근접으로 직접 때린 피해에만 적용** (원거리 스킬·지속 피해 제외)
- 보스·대형 적에게는 회복 상한을 두어 무한 회복 방지
- 회피 없이 맞아가며 싸우면 회복보다 피해가 커지도록 적 공격력 설계

#### 교대 스킬 (폼 전환 스킬)
폼을 전환하는 순간 발동되는 스킬. 전환 자체를 전투의 일부로 만드는 것이 목적.

| 전환 방향 | 교대 스킬 | 역할 |
|---|---|---|
| 빛 → 어둠 | **어둠 폭발** — 근접 범위에 폭발을 일으켜 적을 끌어당김 | 원거리에서 근접전으로 진입과 동시에 딜 (돌진 베기와 역할 구분) |
| 어둠 → 빛 | **빛 폭발** — 넉백 + 짧은 무적 | 근접전에서 안전하게 이탈 |

- 발동 조건: 전환에 성공할 때마다 발동 (전환 쿨타임이 곧 교대 스킬의 쿨타임 역할)
- 전환 쿨타임: **1초**
- 쿨타임 표시: HUD 강화 표시 아래의 폼 표시(현재 폼 색 다이아몬드 + 다시 차오르는 막대)
- 쿨타임 중 Space 입력 시: 무시 (경고음·연출은 사운드 도입 후 [ ])
- 전환 중 무적 시간: 어둠 → 빛 전환 시 **0.5초**, 빛 → 어둠은 없음
- 교대 스킬 수치: 어둠 폭발 = 반경 2타일, 피해 15, 1.2타일 끌어당김(플레이어 0.6타일 앞에서 멈춤). 빛 폭발 = 반경 2타일, 피해 없음, 2타일 밀쳐냄

#### 기타
- 회피: 우클릭 구르기 (폼 공용). 0.3초 동안 2.5타일, 그동안 전부 무적. 쿨타임 0.8초 (구르기 시작부터). 스태미나 없음
- 달리기: Shift를 누르는 동안 이동 속도 1.6배
- 방어: [없음 / 있음]
- 피격 처리: [ ]
- **플레이어 사망 시**: 화면이 어두워졌다가(0.8초) 완전히 어두운 순간 부활 지점으로 옮겨지고 다시 밝아짐. 체력은 모두 차고 흡수한 힘은 유지, 부활 후 1.5초 무적. 잿빛 침식 사망도 같은 처리 (5.4 참고)
  - 부활 지점: **마지막으로 쓴 신전의 제단 앞**. 아직 신전을 쓰지 않았으면 리미나의 돌기둥

### 5.4 성장 시스템 — 빛과 어둠의 흡수
일반적인 경험치·레벨업 대신, 쓰러뜨린 잿빛의 존재에게서 힘을 흡수해 성장한다.

**흡수**
- 잿빛의 존재를 쓰러뜨리면, 그 존재가 **원래 빛의 피조물이었는지 어둠의 피조물이었는지**에 따라 해당 힘을 흡수
- 빛의 힘과 어둠의 힘은 각각 따로 누적됨
- 보스 처치 시 흡수: 잿빛 변이체는 원래 소속의 힘을 대량 흡수, 신의 말은 빛의 말이든 어둠의 말이든 **빛과 어둠이 동일하게** 오름 (균형도에는 영향 없음)

**힘의 기원**
- 이 흡수 능력은 신이 주인공에게 준 힘 (3.5 참고)이며, 주인공에게 높은 잠재력이 있는 이유이기도 함

**세 번째 힘 — 잿빛 (진엔딩 관련)**
- 진엔딩에서는 빛·어둠에 더해 **잿빛의 힘**까지 사용 (획득: 마지막 선택에서 최초의 잿빛의 존재가 남긴 잿빛을 받아들일 때, 4.4 참고)

**강화**
- 빛과 어둠 **양쪽 힘이 모두 일정량 이상 쌓이면** 능력이 강화됨
- 흡수한 힘은 두 곳에 동시에 쌓임
  | 구분 | 역할 | 강화 시 |
  |---|---|---|
  | **그릇** (빛/어둠 게이지) | 다음 강화까지의 진행도. HUD 다이아몬드 게이지에 표시 | 비워짐, 그릇 용량 증가 |
  | **누적 흡수량** (빛의 힘/어둠의 힘) | 지금까지 흡수한 총량. 스킬 위력 보정과 균형도 계산에 사용 | **유지됨** (초기화하지 않음) |
- 강화 효과: 양쪽 그릇이 모두 차면 그릇을 비우고 **용량 +4, 최대 체력 +10, 체력 전회복**. 그릇이 커지면 허용 불균형 범위도 넓어짐 (아래)
- 강화 요구량: 그릇 용량 (처음 12, 강화마다 +4)
- 스킬 위력: 강화 단계와 별개로 **누적 흡수량**에 비례 (6장 데미지 공식)

**균형과 잿빛 침식**
- 경계에서 태어난 자가 잿빛의 영향을 받지 않는 이유는 빛과 어둠의 힘이 **균형**을 이루기 때문
- 한쪽 힘만 지나치게 흡수하면 균형이 무너져 잿빛의 영향을 받아 **사망**
- 이 침식은 잿빛 엔딩에서 **스스로 빛과 어둠을 버리고** 잿빛이 되는 것과 별개 (4.4 참고)
- 허용 불균형 범위: 누적량 차이가 **그릇 용량 × 2.5** 이내 (처음 30 = 한쪽만 약 6마리). 그릇이 커질수록 넓어져서 후반에도 부담이 비슷하게 유지됨
- 불균형 경고 방식: 허용 범위의 **50%부터** 단계적으로
  - HUD: 다이아몬드 게이지 가운데의 **균형 바늘**이 기운 쪽으로 움직이고(50% 지점에 눈금), 경고 구간에서는 바늘과 게이지 테두리가 잿빛으로 물듦
  - 캐릭터: 몸통 색과 발밑의 빛·어둠 광원이 회색으로 바램
  - 화면: 월드 위에 옅은 회색 막
- 사망 전 단계적 페널티: 허용 범위를 넘는 동안 **체력이 계속 깎임** (넘는 순간 초당 4, 허용 범위만큼 더 넘을 때마다 초당 +20). 무적 시간과 무관. 반대쪽 적을 잡아 범위 안으로 돌아오면 멈춤. 침식 중에는 체력바가 회색이 되고 게이지 테두리와 화면의 회색 막이 깜빡임
- 침식으로 죽은 뒤: 부활할 때 많은 쪽 누적량을 줄여 차이를 경고 시작점(허용 범위의 50%)으로 되돌림 → 부활하자마자 다시 침식되지 않는 대신, 힘을 일부 잃는 대가
- 플레이어가 흡수를 거부하거나 조절할 수 있는지: [ ]

**초반 / 중반 흐름과 기운 감지**
| 시기 | 지역 특성 | 흡수 양상 | 위험도 |

**설계 의도**

## 7. 적 / 몬스터

### 7.1 일반 몬스터 — 잿빛에 침식된 각 나라의 병력
잿빛의 존재는 잿빛에 침식된 **빛의 나라 / 어둠의 나라의 기사와 마법사**. 원래 소속(빛/어둠)에 따라 공격 방식과 모션이 달라, 플레이어는 이를 보고 어느 힘을 흡수하게 될지 구분할 수 있다.

| 종류 | 원래 소속 | 전투 거리 | 공격 방식 (초안) | 모션 특징 (초안) |
|---|---|---|---|---|
| 침식된 빛의 기사 | 빛 | 근거리 | 정면 베기 (0.5초 준비 → 앞쪽 100°·1.2타일, 피해 14, 쿨 1.6초). 방패: 정면 120°에서 오는 빛 공격(광탄·관통 광선) 피해 절반 | 곧은 자세, 칼을 머리 뒤로 들어 올렸다 내려침 |
| 침식된 어둠의 기사 | 어둠 | 근거리 | 2연속 베기 (0.3초 준비 → 7, 0.45초 뒤 7). 돌진 (3~5타일 거리에서 0.5초 경로 표시 → 4타일 돌진, 피해 12, 쿨 5초) | 낮게 숙인 자세, 빠름 |
| 침식된 빛의 마법사 | 빛 | 원거리 | 광탄 (0.6초 영창 → 초당 6타일, 피해 10, 쿨 2초). 낙뢰 (플레이어 위치에 1초 표시 → 반경 1.2타일, 피해 18, 쿨 6초) | 5타일 거리 유지, 제자리에서 영창 |
| 침식된 어둠의 마법사 | 어둠 | 원거리 | 유도 암구체 (0.5초 시전 → 초당 4.5타일, 천천히 따라옴, 피해 10, 쿨 2.5초). 저주 장판 (플레이어 위치 반경 1.3타일, 0.5초 뒤부터 3초 동안 0.5초마다 4, 쿨 7초) | 4타일 거리에서 옆으로 돌며 시전, 바닥 위에 떠 있음 |

- 체력: 빛의 기사 50, 어둠의 기사 35, 마법사 25. 이동 속도: 기본 2.5타일/초 × 빛의 기사 0.8 / 어둠의 기사 1.25 / 마법사 0.9
- 모든 공격에는 **준비 동작**이 있음. 기사는 바닥에 공격 범위(부채꼴·돌진 경로)를 표시하고, 마법사는 영창 자세가 경고 역할을 하며 낙뢰·장판은 떨어질 자리를 스스로 표시함
- 준비 중이거나 돌진 중인 적은 교대 스킬로 밀거나 당기면 공격이 취소됨

- **기존 프로토타입 몬스터 3종(Brute/Stalker/Crawler)은 폐기하고 위 4종으로 새로 만든다** (기존의 무작위 소속 방식도 폐기, 종류마다 소속 고정)

**구분을 쉽게 만드는 장치**
- 모션과 공격 패턴을 다르게 (기획 방향)
- 실루엣과 무기 형태를 소속별로 다르게
  - 빛: 곧고 각진 자세. 기사는 큰 방패와 머리 위 후광, 마법사는 날개 모양 어깨·뾰족한 두건·구슬 지팡이
  - 어둠: 낮고 날카로운 자세. 기사는 뿔 투구·어깨 가시·양손 곡검, 마법사는 낮은 두건·찢어진 밑단·바닥 위에 떠 있음
- 몸은 모두 잿빛이고, 눈과 문양(빛: 가슴의 마름모·후광, 어둠: 가슴의 사선·눈)에만 소속 색이 바랜 채로 남음
- 초반(경계 지역)에는 기운 감지 패시브가 없으므로, 위 시각적 단서만으로 구분 가능해야 함

**플레이어 폼과의 관계**
- 근거리 적(기사)은 접근하는 성격이라 빛폼(원거리)으로 상대하기 쉬움, 원거리 적(마법사)은 어둠폼(근거리)으로 파고들어 잡는 것이 유리
- 처치한 적의 소속에 따라 흡수하는 힘이 결정됨 (5.4 참고)
- 이들은 **일반 몬스터**이며 보스로 쓰지 않음 (보스는 7.3). 정예 변형 여부: [ ]

### 7.2 몬스터 AI 행동 (FSM)
```
Roam(배회) → (플레이어 감지) → Chase → (사거리 진입) → Windup(준비) → [Charge(돌진)] → Recover(경직) → Chase
                                   ↓ HP 0
                                  Dead
```
- 감지 범위: 5.5타일. 8.5타일보다 멀어지면 추격을 포기하고 원래 자리로 돌아감
- 공격 사거리·쿨다운: 종류별로 다름 (7.1 표)
- 공격 방향은 준비를 시작할 때 고정되므로, 준비 중에 옆으로 피하거나 구르면 피할 수 있음
- 기사는 다음 공격이 준비되지 않았으면 플레이어에게 바짝 붙지 않고 팔 길이쯤에서 기다림. 마법사는 너무 가까워지면 물러섬

### 7.3 보스
침식된 기사·마법사는 일반 몬스터이며 보스가 아님. 장 보스는 두 유형으로 구성한다.

| 유형 | 설명 | 등장 | 처치 시 흡수 |
|---|---|---|---|
| **잿빛 변이체** | 잿빛에 완전히 잠식되어 이성과 형체를 잃고 거대한 이형으로 변한 존재. 원래는 빛 또는 어둠의 피조물 | 프롤로그, 1장, 4장 | 원래 소속의 힘을 대량 흡수 |
| **신의 말** | 신이 놀이판에 두고 지키는 수호자 형태의 존재. 왕에게 이르는 관문 | 3장 (빛의 땅·어둠의 땅 각각) | **빛과 어둠이 동일하게** 오름 (빛의 말, 어둠의 말 모두) |

- 잿빛 변이체는 잿빛의 위협을 직접 보여주는 보스, 신의 말은 세계의 이상한 점을 암시하는 보스
- 3장(5~7단계)은 신의 영향에서 벗어나기 전이라, 신의 말의 정체는 플레이어가 후반(8단계 이후)에야 돌아보며 이해하게 되는 복선 [제안]
- **의문을 심는 복선**: 빛의 땅의 신의 말을 쓰러뜨려도, 어둠의 땅의 신의 말을 쓰러뜨려도 빛과 어둠이 똑같이 오름 → "왜 빛의 존재를 쓰러뜨렸는데 어둠도 오르지?"라는 의문을 주고, 두 나라가 같은 신을 믿는다는 진실(8단계)과 이어짐
  - 중반에 얻는 기운 감지 패시브로 신의 말을 보면 빛과 어둠의 기운이 섞여 보이게 연출 [제안]
  - 설명은 후반(8단계 이후)까지 주지 않고, 플레이어가 스스로 의문을 갖게 함
- 각 보스는 시스템과 연결: 잿빛 변이체는 한쪽 힘 쏠림을 유도하는 전투, 신의 말은 빛·어둠 균형을 시험하는 전투 [제안]

| 이름 | 등장 지역 | 패턴 요약 |
|---|---|---|
| 프롤로그 보스 | 경계인의 숨은 마을과 숲 | 잿빛 변이체. [마을을 습격하는 첫 보스] |
| 1장 보스 | 나라의 경계 지역 | 잿빛 변이체. [빛·어둠 기운이 섞인 변이체] |
| 3장 보스 (빛의 땅) | 루멘 방면 | 신의 말 (빛). [ ] |
| 3장 보스 (어둠의 땅) | 테네브라에 방면 | 신의 말 (어둠). [ ] |
| 빛의 왕 **루키우스** | 루멘 | [빛 계열 공격. 주인공이 빛폼 고정 상태로 싸우므로 원거리전이 중심] |
| 어둠의 왕 **녹티스** | 테네브라에 | [어둠 계열 공격. 주인공이 어둠폼 고정 상태로 싸우므로 근접전이 중심. 지략가 성격에 맞게 패턴 변화·함정 등 활용] |
| 4장 보스 | 빛·어둠의 전선 | 잿빛 변이체. [빛과 어둠의 재충돌이 벌어지는 전선] |
| 최초의 잿빛의 존재 **키니스** | 잿빛의 중심지 | 첫 대면은 대화, 재대면은 신의 영향 아래에 들어가 대화 없이 전투(진엔딩 조건 충족 시). 쓰러진 뒤 죽기 직전 세계의 진실을 전함 |
| 신 **「   」** (진엔딩 최종 보스) | 신의 영역 | [빛·어둠·잿빛 세 힘을 모두 활용해야 하는 전투 구조] |

**왕 전투 설계 아이디어 (초안)**
- 빛의 왕: 뒤틀린 선의를 표현하는 연출 — 회복·보호막처럼 "지키는" 능력이 공격에 섞여 있어 전투 중 위화감을 줌
- 어둠의 왕: 지략가 성격을 반영 — 플레이어 행동에 반응해 패턴을 바꾸거나, 지형·소환수로 압박하는 페이즈 전환
- 녹티스의 체력 관리 난이도 (제안): 피흡이 가능한 만큼 회복이 쉬워지지 않도록 **회복하려고 붙을수록 위험해지는 구조**로 설계
  - 피흡을 노려 접근하는 플레이어를 응징하는 반격·함정 패턴 (지략가다운 "회복의 유도와 응징")
  - 공격 가능한 틈을 짧게 주어, 피흡할 수 있는 시간이 많지 않게 함
  - 한 번에 큰 피해를 주는 패턴을 섞어, 체력을 어느 정도 유지해야 버틸 수 있게 함
  - 일정 페이즈에는 피흡이 줄거나 무효화되는 구간 [ ]
- 두 왕전 모두 플레이어는 한쪽 폼 고정이므로, 왕의 패턴도 그 제약 안에서 풀 수 있게 설계
